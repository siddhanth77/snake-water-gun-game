# 🐍 Snake Water Gun Game

A simple command-line **Snake Water Gun game built using Python**.  
This project is beginner-friendly and demonstrates basic Python programming concepts such as dictionaries, user input, the `random` module, and conditional statements.

## 🎮 Game Rules

The game has three choices:

- 🐍 Snake
- 💧 Water
- 🔫 Gun

The winning rules are:

- 🐍 Snake beats 💧 Water
- 💧 Water beats 🔫 Gun
- 🔫 Gun beats 🐍 Snake
- Same choice → Draw

## 🛠️ Technologies Used

- Python
- Random Module
- Dictionaries
- Conditional Statements
- User Input
